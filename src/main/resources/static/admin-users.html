Полный доступ к документам всех ЮЛ
Пользователи этого списка видят документы всех юридических лиц, минуя привязку групп к ЮЛ (dbo.rag_full_access_users). Логин — доменный sAMAccountName (как в таблице выше), без домена, нижний регистр. «Кем выдано» фиксируется автоматически. Отзыв (✕ «активен») действует в течение минуты — доступ кэшируется на стороне сервера.
